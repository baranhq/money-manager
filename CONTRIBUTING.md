# Contributing

Changes are submitted as pull requests. Keep changes focused, describe the user-visible or maintenance impact, and disclose any third-party code or assets with their source and licence. Do not submit material with unknown or incompatible rights.

## Contributor Licence Agreement

Every human contributor must accept [CLA version 1.0](CLA.md) before their pull request is merged. The CLA lets the Maintainer distribute contributions under AGPL v3.0-only and separately offer proprietary or commercial licences, while each contributor keeps their copyright. Third-party material remains under its own terms.

Before requesting review, each contributor must post this statement as a comment on the pull request:

> I have read and agree to Money Manager Contributor Licence Agreement version 1.0 dated 23 November 2026. I grant the rights in it for all Contributions in this pull request, including changes I have already pushed, and future Contributions I submit to the project.

The Maintainer checks that the comment was posted by each contributor and co-author, and that it predates the merge. The pull request and its timestamped acceptance comment are the record of acceptance. If an employer or another rights holder may own a contribution, the Maintainer must obtain and retain that party’s separate written authorisation before merging. Do not merge a pull request until these checks are complete.

For code changes, run the relevant checks described in the [README](README.md). For third-party dependencies or assets, update the records and notices described in [LICENSES.md](LICENSES.md).
